# Direction de l'interface

Question : peut-on comprendre le World en le regardant vivre, sans lire ses fichiers techniques ?

## Palette

* Nuit : `#07101b`, le vide autour du globe.
* Air : `#a8e6ef`, les perceptions et les signaux.
* Eau : `#5574c9`, les croyances, rêves et négociations.
* Feu : `#f47b45`, les transformations autorisées.
* Terre : `#b89266`, les preuves, états et reçus.
* Vie : `#8bd19a`, la santé et la croissance.

## Typographie

`Avenir Next` porte les mesures et les actions. `Iowan Old Style` porte les récits des êtres. Les deux sont des familles système avec des replis lisibles, sans chargement distant.

## Trois vues

```text
Orbite                    Atlas                     Profondeur
┌──────────────┐          ┌──────┬─────────┐        ┌──────────────┐
│              │          │êtres │ champs  │        │     Air      │
│    globe     │          │      │         │        ├──────────────┤
│              │          │      │ rivière │        │     Eau      │
├───────┬──────┤          ├──────┴─────────┤        ├──────────────┤
│climat │ être │          │ événement      │        │     Feu      │
└───────┴──────┘          └────────────────┘        ├──────────────┤
                                                  │    Terre     │
                                                  └──────────────┘
```

Orbite donne la sensation du monde. Atlas montre ses relations. Profondeur montre comment un événement traverse les phases. Toutes les valeurs viennent du même état vivant.

## Une forme issue de l'état

L'interface possède une grammaire commune aux trois vues :

* la saison change le récit, la palette et la forme du signe vivant ;
* la pression étend les halos autour du globe ;
* l'entropie accélère les pulsations et rend le ciel plus dense ;
* la vitalité règle la respiration lumineuse des habitants ;
* les seize derniers événements révèlent la force dominante ;
* les relations et les positions dérivent lentement avec le climat ;
* une naissance, un refus ou une nouvelle saison produit une transition brève.

Ces transformations restent graduelles. Elles rendent l'évolution perceptible sans déplacer brutalement les repères de lecture. L'écran indique aussi les causes de sa forme actuelle : humeur, force dominante, rythme et nombre d'espèces connues.
